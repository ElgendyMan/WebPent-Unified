# Plan: v85 Red Team — Judgment Council Hardening

Date: 2026-10-16. Scope: everything under `src/webpent/jc/`, `src/webpent/cli/jc.py`,
`tests/jc/`. Method: every defect gets a failing test (red) before its fix (green).
Laws untouched: JC-L-1..10, L-1..8. Advisory-only, deterministic, zero network.

## Confirmed defects (repro-backed)

### RT-01 — P0 crash: ZeroDivisionError in the judge (repro executed)
File: `src/webpent/jc/judge.py`, the reasoning f-string divides `top_score / total`
before the zero guard applies. When every advocate scores 0 (e.g. all argued with
empty evidence), `total == 0.0` and `judge.rule()` raises `ZeroDivisionError`.
Repro: chamber + one hollow argument (evidence=[]) appended directly, then
`close()` -> ZeroDivisionError. The verdict must instead escalate with the
"nothing scored positive" reason and a safe agreement of 0.0.

### RT-02 — P1 wiring gap: nothing writes sessions.jsonl
Files: all of `src/webpent/` (grep-verified readers only). The bias detector
(U-JC-8), the dashboard bias view and the CLI `jc sessions` command all READ
`sessions.jsonl`, but no production module WRITES it. In production the detector
is starved and `jc sessions` always reports an empty state; only hand-written
test fixtures ever exercise it. Fix: `CouncilMemory.record()` also appends a
bias-compatible compact session row (session_id, ts, scores from
verdict.advocates_summary, argue_orders from the same summary, question) to a
sibling `sessions.jsonl`; `CouncilDashboard` and the CLI already read that path.

### RT-03 — P1 correctness: CLI `verdicts --limit N` under-reports (repro executed)
File: `src/webpent/cli/jc.py`. The command slices the last N RAW memory rows and
only then filters `isinstance(r.get("verdict"), dict)`, so link_outcome rows in
the window shrink the output. Repro: 3 verdicts + 2 link_outcome rows + 2 older
verdicts -> `--limit 5` returned 3. Fix: filter first, then slice.

### RT-04 — P1 config validation: load_verdict_rules accepts nonsense (repro executed)
File: `src/webpent/jc/verdict.py`. A YAML config with `high: 0.3, medium: 0.7`
produces a rules object whose tier() calls 0.5 "high" while should_escalate()
calls it escalation-worthy; `high: 2.5`, `medium: -1`, `tie_epsilon: -0.5`,
`clear_winner_ratio: 0.2` are all accepted as-is. Fix: clamp thresholds to
[0,1], enforce high >= medium (swap if inverted), require tie_epsilon in
(0, 0.5] and clear_winner_ratio >= 1.0, else keep defaults (fail-soft).

### RT-05 — P2 skeptic signal-to-noise: confirmation fires on a single evidence item
File: `src/webpent/jc/skeptic.py`. `len({e.kind}) == 1 and len(evidence) >= 1`
is trivially true for one item, so every default advocate (each cites exactly
one evidence) gets the confirmation flag and +0.15 severity on every challenge.
A single citation is "thin", not "confirmation bias". Fix: require
`len(evidence) >= 2`. Existing tests stay green: the unit test for the flag
uses two same-kind items; the clean-argument baseline uses two kinds.

### RT-06 — P2 contract drift: `general_doubt` flag is undocumented
File: `src/webpent/jc/skeptic.py`. The skeptic emits `general_doubt` in
`bias_flags`, but the documented flag set (BIAS_FLAGS, 7) does not include it
— a transparency gap (JC-L-3): consumers cannot know this value exists. Fix:
export `SKEPTIC_FLAGS = BIAS_FLAGS + ("general_doubt",)` from skeptic.py,
document it in the module docstring, and add a test that every flag emitted by
the skeptic is in the documented set.

### RT-07 — P2 resource leak: mkstemp files left behind on IO failure
File: `src/webpent/jc/memory.py`. `_rewrite()` and `record()` create a tempfile
via mkstemp; if the write or the atomic replace fails, the .tmp file stays in
the state directory forever. Fix: unlink the temp path on failure paths.

### RT-08 — P3 named constants: magic numbers hide policy
Files: `src/webpent/jc/advocates.py` (Economist submit threshold 50.0 USD,
Adapter collapse ratio 0.5), `src/webpent/jc/skeptic.py` (recency window 30
days inline). Transparency (JC-L-3) requires policy numbers to be named,
documented constants. Fix: `ECONOMIST_SUBMIT_THRESHOLD_USD`, `ADAPTER_COLLAPSE_RATIO`,
`RECENCY_DAYS` module constants, referenced in code and docstrings.

### RT-09 — P3 cleanup: dead parameter in the skeptic
File: `src/webpent/jc/skeptic.py`: `_counter_evidence(arg, flags)` never uses
`flags`. Remove the parameter and update the call site.

### RT-10 — P3 cleanup: duplicated assignment in the explainer
File: `src/webpent/jc/explainer.py`: `_full()` re-assigns `data["reasoning"]`
(identical value, already set by `_summary()`). Remove the duplicate line.
