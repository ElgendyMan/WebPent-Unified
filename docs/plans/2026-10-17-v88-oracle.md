## Design decisions

- New package `src/webpent/oracle/` — self-contained dataclasses (Finding,
  Target local to the package; no coupling to the older `attack_graph`
  package or apex). Shared types + sanitization/PII helpers in
  `oracle/models.py`.
- **No network code in the package** (L-10/L-2, mirroring apex): every
  OSINT source is an operator-injected fetcher; the aggregator owns config
  validation, rate limiting, sanitization, PII filtering and the
  zero-touch proof. A guard test AST-scans the package for network imports.
- Config: `config/oracle/osint_sources.yaml` (15 sources, rate limits,
  legal basis), `attack_signatures.yaml` (inference rules, CVE map, signal
  strengths, ≥10 chain patterns, ≥8 escalation strategies),
  `graph_rules.yaml` (criticality defaults, edge weights, entry/target
  rules), `perspectives.yaml` (6 perspectives).
- CLI `src/webpent/cli/oracle.py` (typer sub-app, registered as
  `webpent oracle`), state under `--oracle-dir` (default `.oracle-state`),
  capped audit.jsonl, PREAMBLE_LINE first on every command.
- L-12 (+250) met via parametrized tests covering every source, signal
  type, chain pattern, escalation strategy, perspective and law, plus
  integration/guard tests. Test plan counts: 79 spec tests + ~180
  parametrized/guard/integration tests ≥ 250.
