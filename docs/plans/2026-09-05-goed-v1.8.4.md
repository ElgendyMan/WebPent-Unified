## Architecture
```
LLM Request -> Provider Pool / Router -> Key A/B/C -> Health/Quota/Circuit Breaker
-> REAL API OK -> Continue research
-> REAL API FAIL -> Retry/rotate -> Key next / Provider next -> all exhausted -> SAFE DEFER/STOP
```

## Key Design Principles (NON-NEGOTIABLE)
1. Runtime artifacts win over reports
2. Mock can NEVER satisfy real-API gates
3. No automatic mock fallback - REAL_API_UNAVAILABLE when all real slots exhausted
4. Historical artifacts IMMUTABLE - v1.8.3 freeze is read-only
5. CausalGuard semantics NEVER modified
6. Secrets exist ONLY in environment injection
7. Independent evaluator for hypothesis usefulness
8. Ground truth isolated - runtime NEVER receives labels/mechanisms/difficulty
9. Replay success = verdict_match AND evidence_match AND seal_match AND replay_executed
10. Honest reporting - if no measurable gain, report REAL_LLM_INTEGRATED_NO_MEASURED_GAIN
