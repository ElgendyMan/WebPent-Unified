# Red Team Plan — v88 THE ORACLE (2026-10-17)

Scope: everything shipped in v88 (`src/webpent/oracle/*`, `src/webpent/cli/oracle.py`,
`config/oracle/*.yaml`, tests). Method: line-by-line audit against the 12 laws,
each confirmed bug fixed failing-test-first, then full suite gate, then a fresh
ZIP with the fixes inside it.

## Confirmed findings

- **RT-01 (L-2, HIGH — fail-open zero-touch guard)**: `ZeroTouchGuard.check`
  passes any URL whose netloc parses empty — `check("target.com/login")`
  (no scheme) raises nothing, and a trailing-dot FQDN `target.com.` bypasses
  both equality and the endswith subdomain test. Fix: strip the trailing dot,
  and FAIL CLOSED when the netloc is empty (fetchers must pass absolute URLs;
  a URL the guard cannot judge is refused).
- **RT-02 (L-3, HIGH — short-secret prefix leak)**: `sanitize_secret` stores a
  4-char prefix, so a secret of ≤4 chars is stored in full (`partial` == value).
  Fix: emit the prefix only when the value is longer than 8 chars.
- **RT-03 (L-3, HIGH — nested secrets survive)**: `_make_finding` and the CLI's
  `_ingest_finding` sanitize only top-level string values; a nested
  `{"meta": {"api_key": "sk-live-…"}}` reaches the ledger and report raw. Fix:
  one shared recursive `sanitize_payload` in models.py, used by both paths
  (the reporter's defensive pass already recurses; now the gather side does too).
- **RT-04 (L-8, HIGH — dangerous default)**: `oracle validate --outcome X`
  without `--result` silently records "confirmed", inflating accuracy on a
  typo. Fix: require `--result` explicitly; refuse the command without it.
- **RT-05 (L-6/L-8, HIGH — non-deterministic graph)**: finding and takeover
  nodes use `uuid4`, so every rebuild yields different node ids: the DOT graph
  differs run-to-run and `oracle predict` hashes node ids into prediction ids,
  so the same logical prediction is re-recorded every run (ledger duplicates,
  double-counted accuracy). Fix: deterministic ids from sha256 of
  (type, category, label, evidence) — idempotency restored.
- **RT-06 (L-7/L-9, MEDIUM — entry-node precedence bug)**: in `entry_nodes`,
  `and` binds tighter than `or`: any node with criticality ≤ 0.6 becomes an
  attack entry regardless of category (a low-confidence credential node, crit
  0.54, becomes the attacker's starting point). Fix: parenthesize to the
  symmetric rule `(type in categories or criticality <= max) and type != host`
  is still too broad; use the intent-matched rule `type in categories and
  criticality <= max` (mirrors `target_nodes`), regression-tested.
- **RT-07 (L-5, MEDIUM — ingest bypasses legal basis)**: `gather
  --findings-json` accepts findings whose `source` is not in
  osint_sources.yaml; the report's scope section then shows an empty
  legal_basis for it. Fix: fail closed on unknown source ids at ingest.
- **RT-08 (L-6, MEDIUM — unclamped confidence)**: `_make_finding` accepts
  confidence outside 0..1 and NaN; NaN poisons every sort and score
  downstream. Fix: clamp to [0,1]; non-finite → 0.5.
- **RT-09 (LOW — DOT injection)**: `export_dot` does not escape quotes or
  backslashes in labels; raw operator data with `"` yields invalid DOT. Fix:
  escape `\` and `"`.
- **RT-10 (LOW — fetcher-module diagnostics)**: `gather --fetcher-module` on a
  missing file or a module without FETCHERS dies with a raw AttributeError.
  Fix: explicit, named typer errors.
- **RT-11 (LOW — audit encoding)**: `_audit` reads/writes without
  `encoding="utf-8"`; non-ASCII commands crash the audit under a non-UTF-8
  locale. Fix: explicit encoding.

Not bugs (adjudicated, no change): failed fetches stamp the rate limiter
(the request was attempted, so the source's budget was touched); dashboard
marks a stage done even with zero entries (presence of the artifact is the
signal); graph `merge` tie-breaking (higher criticality wins is documented).
