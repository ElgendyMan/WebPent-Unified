## ما بُني (من الكود الحي)

### 1. العقد المركزي — `src/webpent/shared/raw_transport.py` (جديد)
`governed_raw_request()` — البوابة الوحيدة المصرّح بها لأي اتصال socket عاري،
وتنفّذ بنود العقد الثمانية كاملة:

| البند | الآلية |
|---|---|
| 1. الوجهة تُفحص ضد النطاق قبل الاتصال | `_authorize_destination`: **فشل مغلق** — لا engagement نشط = لا اتصال عاري إطلاقًا؛ الرابط المكتشف ليس منحًا |
| 2. تثبيت DNS/IP ضد rebinding | `_pin_ip`: أول حل يُثبّت والاتصال يذهب للـIP المثبت (نمط B6(b) معمم) |
| 3. الأصل/المسار/المنفذ/البروتوكول/الطريقة | تفويض لـ`is_engagement_origin_allowed` — والمسار الحرفي (قناة D5) يُفحص **بشكله المُفك** (dot-segments محلولة) فلا يهرب من السياسة عبر `..` |
| 4. أصول ثانوية مصرّحة فقط | نفس التفويض — URL لا يطابق سياسة معلنة = مرفوض |
| 5. كوكيز مربوطة بأصلها | `cookie_origin` إلزامي مع الكوكيز؛ **يُفحص قبل قرار الأصل** فمحاولة العبور بين الأصول لا تظهر أبدًا كطلب مصرّح |
| 6. نفس حدود rate/budget | `_admit_rate`: نفس بوابة `_transport_rate_gate` للعميل الآمن — بلا استثناء |
| 7. سقوف الاتصال/الرد/الترويسة/المهلة | 1MiB رد + 64KiB ترويسة + timeout + **وضع صفر redirect** (الإعادة توجيه حقيقة مسجلة لا وجهة جديدة) |
| 8. قرار سياسة مُهيكل مسجل | `RawTransportDecision` لكل محاولة مسموحة **ومرفوضة** — سجل محدود قابل للتدقيق لكل engagement |

### 2. ترحيل قناة D5 — `production/detection_lanes_48.py`
- `_raw_socket_request` أصبح غلافًا فوق العقد: نافذة engagement scoped
  (نفس نمط `_send`)، الرفض يعود كحقيقة سياسة `RawTransportRefused`
  في `structured_fields` — **فشل مغلق، لا تراجع لاتصال غير محكوم**.
- **بوابة lab-only**: `raw_path_channel_enabled()` — الذراع العاري لا يعمل
  إلا بتصريح معمل معزول صريح (`enable_umdr48_raw_path_lab_only` في الـstate
  أو `engagement_isolated_lab` في الإعدادات). على engagements حقيقية:
  الذراع يُتخطى كليًا. تعليق الكود القديم "scope still enforced" كان
  **ادعاءً بلا آلية** — الآلية الآن هي العقد.

### 3. توحيد النواقل الموجودة (إعادة استخدام قبل الإنشاء)
