# UMDR42 CLOSURE — مراجعة الأمان (2026-11-20)

## النطاق
مراجعة التغييرات الأمنية في فرع `security/umdr42-closure` (6 التزامات فوق `5a7e511c` المنشور): إصلاحات سلطة النطاق، إعادة توليد G-02، إعادة تثبيت الملفات المجمدة، وإعادة توثيق BUILD_INFO.

## 1. سلامة إبطال النطاق (P1-SCOPE-REVIVE) — أُغلق
- **العيب:** `clear()` كان يُطلن أحدث صف نشط فقط، و`current()` كانت ترشّح الإبطال قبل اختيار الأحدث — فإبطال v2 كان يُحيي سياسة v1 الأقدم والأوسع (ترقية تنازلية خطيرة للصلاحيات).
- **الإصلاح:** `clear()` يُطلن كل الصفوف النشطة؛ القراءات الثلاثة تختار الأحدث ثم تراعي الإبطال.
- **التحقق السلبي:** اختبار `test_clear_revoked_v2_must_not_resurrect_v1` فشل على النشر الأصلي أولًا (RED) ثم نجح (GREEN)؛ `redacted()` لم تعد تُسرّب engagement مبطلاً.

## 2. فشل مغلق عند غياب السلطة (P1-SCOPE-API-500) — أُغلق
- نقاط النهاية الأربع للنطاق تحوّل `ScopeStoreUnavailable` إلى 503 قابل لإعادة المحاولة — لا 500 غامض ولا استجابة fail-open. مُثبت بـ TestClient عبر monkeypatch لمخزن مُعطّل.

## 3. سلطة واحدة عبر العمليات (P1-SCOPE-WORKER-INIT + COMPOSE) — أُغلق
- الـ worker يستهلك نفس عقد `WEBPENT_SCOPE_STORE_*` (fail-closed عند فشل التهيئة — SystemExit، لا ترقية صامتة لذاكرة محلية).
- compose يمرر env + volume مشترك لخدمتي api وworker.
- **حد:** التحقق التشغيلي الفعلي لـ compose يتطلب Docker (غير متاح هنا) — مصنف BLOCKED تشغيليًا، الإصلاح مُتحقق منه على مستوى الكود والاختبارات.

## 4. G-02 — لا مساس بالموافقات
- إعادة التوليد ببروتوكول r9a: صفر إضافات/حذف هويات (البوابة fail-closed صمدت)، انزياح أسطر فقط. لا موافقات منتهية (اختبار no-expired-approvals PASS). لم يُضاف أي موقع transport خام.
- **قرار المالك المطلوب:** أي تجديد مستقبلي للموافقات بعد 2027-02-17 يبقى بيد المالك الأمني (fail-closed محفوظ).

## 5. نزاهة سلسلة التأكيد — غير مُساسة
- التعديلات في طبقة سلطة النطاق والنقل فقط؛ CausalGuard وProofBundle وnegative controls لم يُلمسا (البوابة المجمدة تثبت بايتات `cqa_v2/causal_guard.py` لم تتغير عن النشر — عيبها المتوارث موثق كـ pre-existing في baseline النشر نفسه).

## 6. نزاهة الدليل — أعيد بناؤها بأمانة
- BUILD_INFO يشير الآن لالتزامات حقيقية قابلة للحل؛ الحسابات منسوخة من سجل الآلة حرفيًا؛ الـ 62 فشلًا موثقة كموروثة بدليل مقارنة بايتية. لا أرقام مخترعة ولا شواهد مزيفة.
